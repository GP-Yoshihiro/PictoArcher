## 1. ひとことで

**石の闘技場に閉じ込められた狩人が、弓だけで魔物の群れを50回しのぎ切る。**

- 原作のアーチャー伝説と同じく弓矢で戦うので、「弓で撃つゲーム」だと見た瞬間に伝わる。
- スライム・骸骨・爆弾など、説明なしで「敵だ」「危ない」と分かる魔物が多い。文字ゼロのゲームと相性がよい。

## 2. フィールド

- 石畳の闘技場（1画面、480×270 の中に壁まで収める）。中にいくつか柱と岩を置き、弾よけにも障害にもなる。
- 10ウェーブごとに時間帯を変える：1〜10 昼／11〜20 夕方／21〜30 夜／31〜40 嵐／41〜50 夜明け前の深い闇（色合いは彩度を抑え、色の意味の5色に見えないようにする）
- 色合いの変化はプログラマーが照明と色調で出す。背景の絵は描き直さない。全体の色合いを変えるだけで、部分的な明かり（たいまつの光の輪など）は出さない。

## 3. キャラクターと敵

| 役割 | 姿 | ひと目で分かる理由 |
|---|---|---|
| プレイヤー | フードをかぶった狩人。弓を持つ | 弓を引く姿で「撃つ人」と分かる |
| 追う敵 | スライム | ゆっくり跳ねて近づく＝体当たり |
| 撃つ敵 | 骸骨の弓兵 | 弓を構える＝撃ってくる |
| 固定砲台 | 目が光る石像 | 動かない、目が光ったら撃つ |
| 自爆する敵 | 足の生えた爆弾（導火線に火） | 爆弾＝近づくと爆発 |
| 中ボス（分裂） | 大スライム | 大きいスライムが小さいスライムに割れる |
| ボスA | オーガ（棍棒） | 突進、地面を叩いてスライムを呼ぶ。20 からは地面を叩いて周りに範囲攻撃 |
| 最後のボス | 黒い竜 | 突進、火を吐く弾幕、雑魚を呼ぶ。HPが半分を切ると目と模様が光る（光り方はプログラマーが出す） |
| 天使 | 羽と光の輪のある天使 | 敵が出ないウェーブに現れる味方 |

**色の注意**：敵の体の主な色に、色の意味の5色（赤・緑・黄・青・紫）を使わない（共通の設計書 §5）。スライムは桃色、骸骨は白灰、石像は灰、オーガは茶、竜は黒などを目安にする。

**弾の見た目**：プレイヤーの弾は白っぽい矢。スキル ◎（周りを回る玉）は白く光る精霊の玉、⟲（跳ね返り）は矢のまま。

### 8週間に収まるか
- 合計 24人日 で、使える 24人日 にちょうど収まる。
- ただし、7週目の終わりまでに描く新しい絵は 23人日 で、使える 21人日 を **約2日はみ出す**。6週目の石像と歩く爆弾から少しずつ遅れ、黒い竜が8週目にずれ込む。
- 理由：魔物は体が柔らかく動く（スライムの伸び縮み、弓を引く腕、竜の首）ので、ロボットより1体あたりのコマが多い。

約2日を減らす対策の候補（どれにするかはデザイナーとチームで決める）
1. 黒い竜の「呼ぶ」の動きを描かず、竜が光るだけにする（雑魚は赤い `!` 円から出る）→ −1人日
2. 歩く爆弾の「膨らむ」を描かず、プログラマーが大きさを変えて出す → −0.5人日
3. 骸骨の弓兵の「崩れる」を 4コマから 2コマにする → −0.5人日
4. 天使を1枚の絵にして、浮く動きをプログラマーが出す → −0.5人日

1〜3 を選べば、ちょうど 21人日 に収まる。

| 直しと統一 | 実際の画面で見て、色・大きさ・並びを直す（新しい絵は足さない） | 3 | 8週目 |

8週間に収まるか：合計 24人日、7週目までの新しい絵 21人日 で、どちらも **ちょうど収まるが余裕はない**。

余裕を作る対策の候補（どれにするかはデザイナーとチームで決める）
1. 仮アイコン12種をプログラマーが作る（プログラマーは工数に余裕がある）→ −1.5人日
2. 操作案内の絵は最小版のまま使い、完成版を作らない → −1人日

## 6. フリー素材（担当：Cさん、約1.5人日）

| 素材 | 探すもの |
|---|---|
| 床と壁 | 石畳と石の壁のタイル（ドット絵） |
| 障害物 | 柱、岩、木箱 |
| エフェクト | 命中、爆発、炎、氷、回復、レベルアップの光、魔法陣 |
| 弾 | 矢、敵の弾（見つからなければプログラマーが図形で作る） |
| 音 | 効果音、BGM（10ウェーブごとに変えられるなら変える） |
| フォント | 数字と記号が入ったピクセルフォント |

- ファンタジーのドット絵素材は CC0（帰属表示が要らないライセンス）のものが多く、探す手間は小さい。候補：Kenney、OpenGameArt（CC0 で絞り込む）。中身とライセンスは取り込む前に確認する。
- ゲーム内にクレジット画面を作ると文字が出るので、CC0 を優先する。
- 取り込む前に文字が入っていないか確認する（看板、本の表紙、巻物、ルーン文字に見える模様も避ける）。

## 8. デザイナーに任せること

- 線の有無、色の数、陰影、頭身などの絵柄（共通の設計書 §11 の大きさの範囲内で）
- 各キャラと敵の細かいデザイン（§3 の役割と「ひと目で分かる理由」を守る範囲で）
- コマ数の増減（増やすときは工数を見直す）
- 描く順番（プログラムで使い始める順に合わせて入れ替えてよい）
- カードの枠と HUD の質感
- §4 と §5 の対策をどれにするか

## 9. この案のよいところと気になるところ

**よいところ**
- 原作と同じ弓矢で、アーチャー伝説らしさがそのまま残る
- 魔物の多くが説明なしで伝わる（初見で分かる、に強い）
- フリー素材が見つけやすい

**気になるところ**
- キャラ担当が7週目の期限を約2日はみ出す。§4 の対策を最初から選んでおく必要がある
- UI担当にも余裕がない（§5）
- ドット絵のファンタジーはよく見かけるので、見た目で目立ちにくい
