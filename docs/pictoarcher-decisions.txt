第1部　チームが決めたこと（決定）
====================================================================

■ 1. ゲームの全体像
- アーチャー伝説型のローグライトアクションを、文字を一切使わずに作る。
- 前提は3つ。
    1. 文字ゼロ（数字・記号・ピクトグラムは使ってよい）
    2. 初見で分かる（説明なしで遊び始められる）
    3. 動かして面白い（触った瞬間に気持ちいい）
- 見た目はヴァンサバ風の2Dドット絵、仕組みはアーチャー伝説。
- ドット絵にするのはキャラクター（プレイヤー、敵、中ボス、ボス）だけ。カード、アイコン、ボタンなどの UI は普通の2Dの絵。
- 敵の数はアーチャー伝説のように少なめ。1体ずつの動きと予兆を見て避ける遊びにする。
- 世界観は SF（ロボット系）。主人公はパワースーツを着た兵士。
- ファンタジー案は使わない。

■ 2. ゴールとやらないこと
ゴール
- 1つのステージ（50ウェーブ）を、説明なしで最初から最後まで遊び切れる。

やらないこと
- 2つ目のステージ
- 敵の大群（画面を埋める数十体〜百体の敵）
- 天使（ボスのあとに出る味方）
- プレイ中の武器の切り替え

■ 3. 制約
- 人数：プログラマー3人、スキル系UI担当1人、キャラ担当1人、デザイナー（補助）1人
- 期間：8週間
- 作業日：全員、週3日くらい（授業などがあるため）
- プログラマーは全員 Claude を使って作る
- エンジン：Unity 6
- 対象：PC。画面は 9:16 の縦長。のちに iPad・iPhone へ対応させるので 9:16 で作る（対応そのものは8週間の範囲外）
- アート：キャラ担当はプレイヤーと敵だけを描く。背景とエフェクトはフリー素材
- 管理：git と GitHub（非公開リポジトリ）

■ 4. 遊び方
- 仕様メモの「総ステージ数 50」は、1つのフィールドでの 50ウェーブのこと。
- フィールドは1画面に収まる広さで、カメラは動かない。
- 今のウェーブの敵を全部倒すと、同じフィールドに次のウェーブの敵が出てくる。
- 射撃は自動。移動中も撃てる。
- 武器は3種（銃、レーザー、ランチャー）。プレイを始める前に1つ選び、プレイ中は変えない。
- 障害物の並びは数パターン用意し、ウェーブごとに切り替える。
- レベルアップで選ぶのは、自分を強くする強化だけ。

■ 5. 敵（通常の敵は7つの見た目で10種）
見た目（モデル）は7つ。モデル1〜3は、同じ見た目で攻撃の違う2種がある。
  モデル1：単発攻撃型／単発範囲型
  モデル2：三発扇型／五発連射型
  モデル3：接触攻撃型／自爆型
  モデル4：地面燃焼型
  モデル5：落雷型
  モデル6：ハンマー回転型
  モデル7：時間制限型（即死）

■ 6. 中ボスとボス
- 中ボス1種、ボス2種（ボスA と最後のボス）。
- 天使はなくす。

■ 7. 強化（15種、カード26枚）
  1. HP回復
  2. 最大HPアップと回復
  3. 攻撃力
  4. 移動速度
  5. 攻撃速度
  6. 弾が増える（5枚）：フロント／ダイアゴナル／サイド／リア／マルチショット
  7. 弾の性質（3枚）：ウォールバウンド／エネミーバウンド／ピアッシング
  8. 属性（4枚）：炎／氷／雷／毒（毒の色は未定）
  9. 攻撃範囲
 10. 自機縮小化
 11. 敵の死亡時に爆発（3枚）：縦／横／円
 12. 敵の死亡時に周りの敵を吸い寄せる
 13. 経験値の取得率
 14. ファンネル
 15. ネタ系（中身は未定）
  6・7・8・11 は中の種類ごとに別のカードになるので、カードは全部で26枚。

■ 8. 文字ゼロのルール（全員必読）
- 禁止：アルファベット・ひらがな・カタカナ・漢字すべて。
  LV、HP、BOSS、x2、s（秒）などの略語・単位も禁止。
- 代わりの表記：レベル ★5／倍率 ×2／時間 ⏱ 30／割合 +20%／進行 23/50
- 色の意味：赤＝危険・攻撃／緑＝回復／黄＝コイン・経験値／青＝防御・氷／紫＝レア
  この5色は UI・拾うもの・エフェクトの意味だけに使い、敵の体の主な色や
  フィールドの照明には使わない。プレイヤーの弾は白。
- 予兆：敵の攻撃は必ず先に赤い線・赤い円で予告する。
- 操作の案内：手・矢印キー・マウスの絵のアニメで見せる。キーの絵に英字を描かない。
- 絵文字：フォントで出さない。すべてスプライト画像（UI の絵）で用意する。
- フォント：TextMeshPro のフォントアセットには数字と記号だけを登録する。
- ボタン：▶ 開始／⏸ 一時停止／↻ やり直し／🏠 ホーム／⚙ 設定／🔒 ロック中／🔊 音量
- 素材：取り込む前に文字が入っていないか確認する
  （UIパックの「PLAY」、看板、ロゴ、背景の張り紙や画面の表示など）。
- 開発ビルドやデバッグ表示でも画面に文字を出さない。ログはコンソールだけ。

第2部　決定にもとづいて設計書に書いた案（チームの確認待ち）
====================================================================

■ 1. 画面と技術
- Unity 6000.5.10f1 に全員固定。URP 2D、Pixel Perfect Camera、Input System。
- 画面は 1080×1920 を基準にし、描画の基準解像度は 270×480（4倍拡大）。
- PC のウィンドウは 540×960。全画面では整数倍で拡大し、左右を黒い帯で埋める。
- 1ユニット＝16px。キャラとフリー素材の画像は Filter Mode を Point、圧縮なしで取り込む。
- UI は uGUI の Canvas（Canvas Scaler は Scale With Screen Size、基準 1080×1920）。UI の画像は Filter Mode を Bilinear で取り込む。
- のちの iPad・iPhone に備えて、UI は画面の端を基準に置き、端に余白をとる。
- シーンは Boot／Home／Run の3つ。武器を選ぶ画面は Home の中。
- 武器・強化・敵・ウェーブ・障害物のパターンは ScriptableObject のデータ。
  数値（HP、攻撃力、速度、出現数など）はコードに直接書かない。
- ビルドは Windows と Mac。

■ 2. 操作
- 移動：WASD／矢印キー、またはマウス左ボタンを押したままドラッグ。
- 射撃：一番近い敵を自動で狙う。敵がいないときは撃たない。
- カード選択：クリック、または 1 2 3 キー。
- 一時停止：Esc で ⏸。
- 被弾したら短い無敵時間（点滅）。

■ 3. 武器3種の撃ち方
- 銃：光弾を1発ずつまっすぐ撃つ。どんな場面でも使いやすい。連射は速い（基準）。
- レーザー：一瞬だけ直線の光線を出し、当たった敵をすべて貫く。連射は遅め。
  レーザーを選んだときは「ピアッシング」をカードの候補から外す。
- ランチャー：小型の弾が当たると爆発し、周りの敵にも当たる。連射は遅い。
- 武器を選ぶ画面はホームで ▶ を押したあとに出す。前回選んだ武器に印を付ける。
- 初回はチュートリアルを銃で遊ぶ。武器を選ぶ画面は2回目のプレイから。

■ 4. ゲームの流れ
- 起動 → 初回はチュートリアル（ウェーブ0）、2回目以降はホーム
  → ▶ → 武器を選ぶ → プレイ（50ウェーブ）→ クリアまたは死亡
- クリア：🏆 ＋ ⏱ クリアタイム ＋ 獲得コイン → ↻ ／ 🏠
- 死亡：💀 → 到達ウェーブ 23/50、選んだ武器と取得した強化のアイコン → ↻ ／ 🏠
- ↻ は同じ武器でもう一度始める。死亡すると強化はリセット。
- 1回のプレイは 20〜30分が目安（1ウェーブ平均 30秒前後）。
- 保存するもの：最高到達ウェーブ、最短クリアタイム、コイン、前回選んだ武器（JSON）。
- プレイの途中では保存しない。

1ウェーブの流れ
  1. 敵が出る位置に赤い ! 円 → 敵が出現
  2. 戦闘
  3. 全滅 → 経験値とコインが自分に吸い寄せられる
  4. 約1.5秒の休み。障害物を次のパターンに変え、23/50 が 24/50 に変わる

■ 5. 障害物のパターン
- 6パターン（数は調整してよい）。どのウェーブでどれを使うかはウェーブのデータに書く。
- 切り替えは休みの間。新しい位置に薄い影を約0.5秒出してから現れる。
- プレイヤーと重なる障害物は、離れるまで出さない（閉じ込めない）。
- ボスと中ボスのウェーブは障害物の少ないパターン。袋小路は作らない。

■ 6. 50ウェーブの構成
- 5・15・25・35・45：中ボス（出る前に ⚠ が点滅）
- 10・20・30・40：ボスA（画面上部に 💀 付きのHPバー）
- 50：最後のボス
- それ以外：通常のウェーブ（前の版で天使だった 11・21・31・41 も通常）
- 敵の種類は少しずつ増やし、26 で10種がそろう。31〜 は組み合わせと強化版で変化を付ける。
- 強化版の敵は少し大きく、色を濃くする（5色にはしない）。
- 10ウェーブごとにフィールドの照明を変える
  （1〜10 白い照明／11〜20 薄暗い／21〜30 暗い紺色／31〜40 ゆっくり明滅／41〜50 惑星の淡い光）。

■ 7. 敵の動き・予兆・登場するウェーブ・姿
  モデル1 一つ目の警備ロボ
    単発攻撃型：止まって狙い1発撃つ。予兆は赤い線。1〜
    単発範囲型：着いた所で爆発する弾。予兆は着く場所に赤い円。11〜
  モデル2 腕に砲が並んだ多連装ロボ
    三発扇型：扇形に3発。予兆は赤い線3本。6〜
    五発連射型：同じ向きに5発続けて撃つ。予兆は太い赤い線。16〜
  モデル3 クモ型の小さな機械
    接触攻撃型：追ってきて体当たり。予兆なし（遅い）。1〜
    自爆型：突進して自爆。予兆は広がる赤い円。6〜
  モデル4 火炎放射ロボ
    地面燃焼型：床に炎を残す（一定時間で消える）。予兆は薄い赤い円。16〜
  モデル5 浮かんでいる送電ロボ
    落雷型：プレイヤーの場所に雷を落とす。予兆は縮む赤い円。21〜
  モデル6 ハンマーアームの作業ロボ
    ハンマー回転型：ハンマーを振り回しながら近づく。予兆は回る範囲に赤い円。11〜
  モデル7 時限装置を抱えたロボ
    時間制限型：頭の上に ⏱ と残り秒数。最後の3秒は画面の縁が赤く点滅。26〜
- 敵の体の色は灰・白・黒・茶が目安。目やランプは白く光らせる。

■ 8. 中ボスとボスの中身
- 中ボス（金属の粒が集まった塊）：HPが減ると分裂する。出るたびに HP・速さ・分裂の数を上げる。
- ボスA（大型の二足メカ）：
    10 は突進（赤い線）と雑魚を呼ぶ（赤い ! 円）。
    20 から範囲攻撃（赤い円）を足す。30・40 は HP と速さを上げ、攻撃の間隔を短くする。
- 最後のボス（ステーションの中枢機械、巨大な一つ目）：
    突進／弾幕／雑魚を呼ぶ の3パターン。HPが半分を切ると色と光り方が変わり、間隔が短くなる。

■ 9. 強化の見え方と重ね取り
- カードには大きいアイコン＋数字＋約1秒の実演アニメを入れる。段階は ★★ のように表示。
- カード3枚は重複なしでランダム。上限に達した強化は候補から外す。
- 全部が上限になったら、カードは ♥回復 と コイン に置き換える。
- 50ウェーブで 20回前後のレベルアップが目安。
- 重ね取りの上限
    HP回復：何度でも（満タンのときは候補から外す）
    最大HP・攻撃力・攻撃速度：最大5
    移動速度・攻撃範囲・経験値の取得率・ファンネル：最大3
    フロント：最大3／ダイアゴナル：最大2／サイド・リア：1回／マルチショット：最大2
    ウォールバウンド・エネミーバウンド：最大2／ピアッシング：1回
    属性（炎・氷・雷・毒）：各 最大3
    自機縮小・死亡時の爆発（縦・横・円）・吸い寄せ：最大2
- 属性の色：炎は赤、氷は青、雷は白い稲妻（黄色はコインと重なるため）。

■ 10. 画面表示（HUD）
- プレイヤーの頭上：HPバー＋数字
- 画面上部1段目：ウェーブ 23/50、⏸（右端）。ボス戦ではボスのHPバー（💀付き）
- 画面上部2段目：経験値バー＋★n、コイン数
- 画面上部3段目：選んだ武器と取得した強化のアイコン一覧
- 戦闘中：ダメージ数字、ヒットストップ、画面の揺れ

■ 11. チュートリアル（ウェーブ0、銃で遊ぶ）
  1. 敵1体だけ。矢印キーとマウスの絵のアニメで動き方を見せる
  2. 近づくと自動で弾が飛ぶ
  3. 1体目を倒すと必ずレベルアップ → カード選択を体験
  4. 2体目は弾を撃つ敵。赤い予兆線を見せる
  5. 倒すと 1/50 が出て、ウェーブ1が始まる
  案内の絵は、その操作を一度したら消える。2回目以降の起動では出さない。

■ 12. 絵の方針（ドット絵はキャラだけ）
- ドット絵で描くのはキャラクターだけ（プレイヤー、敵、中ボス、ボス）。すべて 32×32 で描く。フリー素材（タイル、障害物、エフェクト）はドット絵の素材を使い、大きさは縛らない。
- 32×32 は 2×2 ユニット（PPU 16 のまま）。
- 中ボスとボスも 32×32 で描き、ゲーム内で 2倍に拡大して表示する（倍率は調整値）。
- カード、カードの枠、強化と武器のアイコン、ボタン、HUD のピクトグラム、操作案内の絵は、ドット絵ではない普通の2Dの絵（UI の絵）で描く。大きさは 32×32 に縛らない（アイコンは 256×256、ピクトグラムは 128×128 くらいを目安に描いて縮めて使う）。
- カードは縦長（縦横の比は 3:2 くらい）。上に強化のアイコン、真ん中に ★ の段階、下に実演アニメ。
- 向きは左右だけ（右向きを描き、左は反転）
- 被弾の白い光りと強化版の色は、プログラマーが出す（別の絵を描かない）
- 絵は PNG のスプライトシート（コマを横一列）で渡す。取り込みは担当のプログラマー。
- フリー素材は CC0 を優先。CC-BY はクレジットをゲームの外に書けば使ってよい。

遅れたときに削る順
  1. ネタ系の強化
  2. 最後のボスの「雑魚を呼ぶ」
  3. ボスAの範囲攻撃
  4. 強化の一部（マルチショット、エネミーバウンド、死亡時の爆発の縦と横）

  予兆表示、チュートリアル、カードの実演アニメは最後まで削らない。

手が空いたら足す候補
  1. ⚙ 設定画面（音量、画面の揺れの強さ）
  2. 手触りの仕上げ
  3. 🏹強化（ホームでの永続強化）

■ 15. 毎週のテストの合格ライン（説明なしで初見の人に渡す）
